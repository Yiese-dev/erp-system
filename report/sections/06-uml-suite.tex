\section{UML Diagram Suite}
\label{sec:uml-suite}

This section presents the complete UML diagram suite required by the project
brief: a use-case diagram, a class diagram, at least two sequence diagrams
(one covering the mandatory cross-service asynchronous workflow), an
entity-relationship diagram, and a deployment diagram showing containers and
the message broker. All diagrams were generated from PlantUML source files
committed under \texttt{report/diagrams/} and are kept consistent with the
delivered code: entity and event names below match the class and column
names used in \texttt{services/*/app/models.py} and
\texttt{packages/campus\_common/events.py}.
