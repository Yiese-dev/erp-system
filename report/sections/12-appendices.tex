\section{Cited Sources and Third-Party Material}
\label{app:sources}

\subsection{Statutory Payroll Rate Sources}
The draft CNPS/IRPP rule set shipped with the demonstration data cites the
following official sources; an HR officer must verify each rate against the
current version of these publications and record the verification before
approving the rule set for use (\cref{sec:hr-module}):
\begin{itemize}[leftmargin=1.4em]
  \item Direction G\'en\'erale des Imp\^ots, \textit{Code G\'en\'eral des
    Imp\^ots}, IRPP salary provisions (professional-expense allowance,
    annual abatement, progressive scale, CAC) --
    \url{https://www.impots.cm/fr/documentation}
  \item Direction G\'en\'erale des Imp\^ots, \textit{Circulaire portant
    instructions relatives \`a l'application de la Loi de Finances 2026} --
    \url{https://www.impots.cm/fr/actualites/circulaire-lf-2026}
  \item Caisse Nationale de Pr\'evoyance Sociale (CNPS) contribution schedule
    (pension, family allowance, work-injury; contribution ceiling) --
    \url{https://www.cnps.cm/}
\end{itemize}

\subsection{Third-Party Software}
Campus ERP is built on open-source software including FastAPI, SQLAlchemy,
Pydantic, PyJWT, Argon2-cffi, pika, ReportLab, qrcode, React, Vite,
TanStack Query, Recharts, Lucide, PostgreSQL, RabbitMQ, NGINX, Prometheus,
Grafana, Loki and Fluent Bit, each used under its respective open-source
licence. No proprietary third-party code was reused.
