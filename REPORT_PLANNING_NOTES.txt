7. KEY FACTS TO QUOTE ACCURATELY IN THE REPORT (do not re-derive, just cite)
--------------------------------------------------------------------------------
- 4 services total (Identity + the 3 required domain modules), each with its own
  PostgreSQL database and least-privilege runtime role; row-level security enforced
  on every tenant-owned table.
- Messaging: RabbitMQ topic exchange "campus.events"; transactional outbox in
  Academic; inbox/idempotency table in Finance; retry queue + dead-letter queue;
  message envelope includes event_id, schema_version, tenant_id, correlation_id.
- Payment simulator mimics MTN MoMo / Orange Money request-to-pay + signed webhook
  callback (HMAC-SHA256); explicitly disclosed as simulated, no real transactions.
- Payroll: CNPS pension, family allowance, work-injury contributions and IRPP/PAYE
  progressive scale with CAC are implemented as an editable, source-cited,
  APPROVAL-GATED rule set (status: draft until an HR officer verifies and approves
  against the official DGI/CNPS publications) - state this honestly in the report,
  do not claim the rates are certified without approval evidence.
- QR attendance: kiosk displays a signed, 60-second-expiring challenge; scanning or
  typing the code checks the employee in/out; not biometric (documented substitute
  permitted by the brief).
- Automated tests: 45+ backend tests across 4 services, ~88% coverage on core
  business-logic domain packages (update with the final CI figure before submission).
- Design tokens: background #F3F6F5 (mist), primary #00695F (teal), accent #B44C3B
  (coral), typography Source Sans 3 / IBM Plex Mono.
